## 🔬 Research

**LLM Evaluation for Clinical Decision Support** *(Ongoing — 2026)*

Evaluating open-source LLMs — Llama 3.3-70B (Groq), Gemini 2.0 Flash, DeepSeek-R1 — against GPT-4o mini for clinical decision making in resource-limited healthcare settings. Using **XGBoost** for disease risk prediction, **SHAP** for explainability, and the **IMPACT scoring framework** for LLM evaluation.

`Python` `XGBoost` `SHAP` `Scikit-learn` `Groq API` `Gemini API`
